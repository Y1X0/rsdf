# Reproducible-build lockfile (Production Hardening Sprint H1/DEP1).
#
# pyproject.toml's own dependency list is intentionally loose (>=) so the
# library stays easy to depend on; this file pins every resolved package
# (direct and transitive, core + "dev" + "production" extras) to the exact
# version verified to work together, for CI and the Docker image to install
# from — not for local development, where pyproject.toml's own bounds are
# still what you want.
#
# Regenerate after any pyproject.toml dependency change:
#   pip install -e ".[dev,production]"
#   pip freeze --exclude-editable > requirements-lock.txt
#
# Includes the "rendering" extra's two packages (Pillow, imageio-ffmpeg) —
# real ffmpeg cutting/caption-burning is core to the clip factory pipeline
# (services/clip_service.py, video_clipping/providers/ffmpeg_clip_renderer.py),
# not an optional nicety like TemplatePillowRenderer still is, so both are
# pinned here rather than left out. Does NOT include the "elevenlabs" extra
# (its own httpx dependency is already covered transitively via anthropic) —
# real TTS still needs `pip install -r requirements-lock.txt -e ".[elevenlabs]"`
# separately.
